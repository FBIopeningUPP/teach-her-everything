# 🚀 Masterclass: C Programming (Teaching Guide)

Welcome to the comprehensive, highly-detailed guide to C. This vault is designed for **you (the teacher)** to guide an absolute beginner, while providing deep-dive "Nerd Notes" so you fully understand the mechanics under the hood.

> [!info] How to use this vault
> - **Main Text:** The simple, beginner-friendly analogy to explain to your friend.
> - **Nerd Notes (Callouts):** Deep technical details for you, so you can answer "but why?" questions.
> - **Visuals:** Use the Mermaid diagrams to explain concepts on a whiteboard.

## 📅 The 2-Day Syllabus

### Day 1: The Machine & Core Logic
1. [[01_Architecture_and_Compilation]] - How computers actually run code.
2. [[02_Syntax_and_Structure]] - Anatomy of a C program.
3. [[03_Data_Types_and_Memory]] - How RAM works, bits, bytes, and variables.
4. [[04_Operators_and_Math]] - Doing math and logic (including bitwise!).
5. [[05_Control_Flow_and_Loops]] - Branching paths and iteration.

### Day 2: Memory & Advanced Structures
6. [[06_Functions_and_Stack]] - The Call Stack, scope, and reusability.
7. [[07_Pointers_Demystified]] - Memory addresses, `&`, and `*`. (The most important chapter!)
8. [[08_Arrays_and_Strings]] - Contiguous memory blocks and the Null Terminator.
9. [[09_Structs_and_Custom_Types]] - Grouping data together.
