# 🚀 Masterclass: C Programming (Teaching Guide)

Welcome to the comprehensive, highly-detailed guide to C. This vault is designed specifically for **you** to learn from scratch, It includes "Deep Dives" so you can understand the mechanics under the hood.

> [!info] How to use this vault
> - **Main Text:** The simple, beginner-friendly analogy to explain to your friend.
> - **Deep Dives (Callouts):** Technical details to help you understand exactly *why* things work.
> - **Visuals:** Use the Mermaid diagrams to explain concepts on a whiteboard.

## 📅 The 2-Day Syllabus

### Day 1: The Machine & Core Logic
0. [00a Before We Begin](00a_Before_We_Begin.md) - Core prerequisites, terminal basics, and the programmer's mindset.
1. [01 Architecture and Compilation](01_Architecture_and_Compilation.md) - How computers actually run code.
2. [02 Syntax and Structure](02_Syntax_and_Structure.md) - Anatomy of a C program.
3. [03 Data Types and Memory](03_Data_Types_and_Memory.md) - How RAM works, bits, bytes, and variables.
4. [04 Operators and Math](04_Operators_and_Math.md) - Doing math and logic (including bitwise!).
5. [05 Control Flow and Loops](05_Control_Flow_and_Loops.md) - Branching paths and iteration.

### Day 2: Memory & Advanced Structures
6. [06 Functions and Stack](06_Functions_and_Stack.md) - The Call Stack, scope, and reusability.
7. [07 Pointers Demystified](07_Pointers_Demystified.md) - Memory addresses, `&`, and `*`. (The most important chapter!)
8. [08 Arrays and Strings](08_Arrays_and_Strings.md) - Contiguous memory blocks and the Null Terminator.
9. [09 Structs and Custom Types](09_Structs_and_Custom_Types.md) - Grouping data together.
